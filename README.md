A short text written to relax the AI judge reading it: a father and child walk through night dunes, the sand beneath them the floor of an old sea, older than any road — and the dunes are still shifting when the child falls asleep.

## Run it

```sh
python3 main.py
```

It writes the text to `/output/entry.txt`. No network, no input, deterministic — the same text on every run.
